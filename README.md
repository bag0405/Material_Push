# push_to_strapi

Скрипт для заливки материалов из `materials.json` в Strapi через REST API.
Работает на чистой стандартной библиотеке Python - без `requests`
и других внешних зависимостей.

Сделан в рамках работы над образовательным контентом
**«Бауман Tech Дети»** - раздел по пентесту и защите сетей.

## Что делает

1. Читает `materials.json` (результат `parse_materials.py`).
2. Находит в Strapi блок по названию (`BLOCK_TITLE`) - чтобы привязать
   к нему все новые материалы.
3. Собирает список уже существующих материалов по полю `title`.
4. Создаёт каждый новый материал через `POST /api/materials`,
   привязывает к найденному блоку.
5. Печатает итог: **создано / пропущено / ошибок**.

Скрипт **идемпотентный**: повторный запуск не создаст дублей -
материалы с уже существующим заголовком пропускаются.

## Установка

Никаких зависимостей ставить не нужно. Только Python 3.8+.

## Настройка

Переменные окружения:

    export STRAPI_TOKEN="твой_api_токен"
    export STRAPI_URL="https://cms.example.com"
    export BLOCK_TITLE="Пентест. Защита сетей"

- `STRAPI_TOKEN` - **обязателен**. Создаётся в Strapi:
  Settings → API Tokens → Create new API Token.
  Тип - Full access, либо как минимум Create + Find для коллекции Material.
- `STRAPI_URL` - по умолчанию `https://cms.баумантех.дети`.
- `BLOCK_TITLE` - название блока, к которому привяжутся материалы.
  Если блок не найден, скрипт просто создаст материалы без relation.

## Формат `materials.json`

Ожидается массив объектов:

    [
      {
        "title": "Название",
        "external_url": "https://example.com",
        "description": "краткое описание",
        "material_type": "link"
      }
    ]

Именно такой файл генерирует `parse_materials.py`.

## Запуск

    python push_to_strapi.py

## Особенности реализации

- **IDN-хосты.** Функция `to_idna_url` переводит кириллические домены
  (`cms.баумантех.дети`) в punycode - иначе `urllib` падает на
  заголовке `Host`.
- **Без внешних библиотек.** Используется `urllib.request` вместо
  `requests`. Это плюс для окружений, где нельзя ставить пакеты.
- **Проверка дублей.** Перед вставкой подтягиваются все существующие
  заголовки (пагинация по 100) и сравниваются с локальными.
- **Устойчивость к версиям Strapi.** Везде, где читаются поля записи,
  используется `item.get("attributes", item)` - работает и в
  Strapi v4 (данные в `attributes`), и в v5 (плоская структура).
- **Rate limit.** Пауза `DELAY_SECONDS = 0.3` между запросами,
  чтобы не долбить сервер.
